Questions, answered first

The questions researchers ask about Twistor Data, answered directly. Dataset-specific answers come first, then the access, pricing, and provenance questions from the catalog page.

Finding a dataset

Where can I download validated subseasonal weather forecast datasets for AI research?

S2S-TRUST, published by Twistor Holdings LLC on Twistor Data, covers subseasonal prediction for weeks 2 to 6. It is built on ERA5 reanalysis, ECMWF reforecasts, and NOAA GEFS, with the truth source named on every record and a sealed-window benchmark harness. Version 1.0 carries 30 rows, delivered by API and Excel download. Access requires an active Twistor subscription.

What are the best open carbon sequestration datasets for machine learning?

CARBON-TRUST, on Twistor Data, is a harmonized carbon-sequestration dataset built for machine learning. It is not a free download: access sits behind a Twistor subscription, with API calls and downloads micro-tolled and capped at $0.10 each. Version 1.0 harmonizes 36 rows across five carbon pools, and every row carries its method code, so Walkley-Black and dry-combustion records never pool silently.

Where can I find trustworthy crop trial data for training a yield prediction model?

CLIMATESHIFT-1, on Twistor Data, publishes crop trial data in a genotype-by-environment-by-management design, hemp-first. Every trial carries its trait panel (THC, CBD, CBG), lab accreditation, certificate-of-analysis hashes, and the management practices behind the numbers. Version 1.0 carries 70 rows, delivered by API and Excel download behind a Twistor subscription.

Access, pricing, and provenance

Is the data real?

V1 seeds are synthetic and labeled as such on every row: we say so upfront. Real-data ingestion is underway, and versions will always tell you exactly what you are looking at.

How do I cite a dataset?

Every release carries a version and a DOI. Cite the version your work ran on; it is immutable and reproducible.

What does the subscription cost?

Access is gated on an active subscription: the gate is binary, on or off. On top of that, everything you pull is metered. API calls by volume, downloads by a dynamic curve. Fees are stated before you incur them. No surprise billing.

Can my whole lab share one subscription?

Yes. Subscriptions are per organization; API keys are issued per key with lane scopes and rate limits.

Do you take data contributions?

Yes: signed lab ingestion with calibration chains is how the gold tier grows. Talk to us about becoming a contributing lab.
